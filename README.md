# gemini-cli

A lightweight, no-nonsense Gemini CLI.

Built to interact with Google Gemini directly from the terminal without the overhead of a web browser. Unlike other projects that require heavy runtimes and massive dependency trees, this tool stays true to the UNIX philosophy: fast, minimal footprint, and zero runtime overhead—just pure Bash, `curl`, and `jq`.

## Installation (Debian / Ubuntu)
